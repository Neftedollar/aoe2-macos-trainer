# AoE2 Mac Trainer 0.6.0 — экспериментальная сборка

Сборка для первого испытания XS-тренера в нативной AoE2 DE на Mac. **Сам запуск внутри игры ещё не проверен.** Требуется Mac с Apple Silicon (M1 и новее), macOS 13 или новее. Готового Intel-приложения в этом выпуске нет.

## Что скачать

Для начала достаточно ZIP с приложением: каталог билдов и экспортёр XS уже встроены.

| Файл в Assets | Назначение |
| --- | --- |
| `AoE2MacTrainer-0.6.0-macos-arm64.zip` | Приложение `AoE2MacTrainer.app`; без дополнительной ZIP-обёртки GitHub Actions. |
| `aoe2trainer_catalog-0.6.0.xs` | Готовый снимок полного каталога для ручного подключения к собственному RMS/сценарию. Отдельно скачивать для работы приложения не обязательно. |
| `builds-0.6.0.json` | Исходный каталог в формате JSON v2 для просмотра и настройки. |
| `SHA256SUMS.txt` | Контрольные суммы файлов выпуска. |

## Первый запуск

1. Распакуй ZIP приложения, перенеси `AoE2MacTrainer.app` в «Программы» и запусти. В верхней строке меню появится 🏰.
2. В PREVIEW вручную выбери цивилизацию и обычный FC без условия по еде — это предпочтение для экспорта, не определение текущего матча.
3. Выбери **«Создать локальный XS-мод каталога → Arena»**. Если папка игрового профиля не найдена автоматически, укажи `mods/local` либо сначала сохрани мод в отдельную папку для переноса.
4. В игре включи созданный локальный мод и запусти одиночный Skirmish на его **Custom Map `AoE2Trainer_*`**, а не на стандартной Arena. При необходимости перезапусти игру, чтобы обновить список карт.
5. Проверь, появились ли игровое время, правильная цивилизация, название билда и цели. Скоростям добычи нужно накопить окно из 60 игровых секунд.

Приложение подписано **ad-hoc**, без нотаризации Apple; macOS может предупредить о непроверенном приложении. Глобально отключать системную защиту не требуется.

## Что нового

- 15 планов: общие учебные FC/FI для 56 цивилизаций и четыре пищевых варианта для шести обычных стартов. Это не 56 оптимизированных военных билдов.
- XS учитывает реальную цивилизацию и уже замеченную поблизости дичь. Неизвестное не считается отсутствием; новые наблюдения не переключают активный билд.
- Строгие `includeOnly`/`exclude`, семейства стратегий и положительные условия по еде в JSON.

Настройка JSON необязательна: **«Открыть пользовательский JSON…» → редактирование → «Перезагрузить JSON-билды»**. Сохрани свои прежние изменения перед заменой содержимого. После правки нужно заново экспортировать мод перед следующим матчем.

## Границы готовности

Внешний оверлей — **PREVIEW**, не получает живые данные XS. `Ctrl+Option+B` пока не переключает билд внутри игры; мост хоткеев ещё не реализован. XS загружается только через специально подключающий его RMS/сценарий, а внутриигровые подписи пока выводятся транслитом. Используй одиночные тренировочные карты; работоспособность в мультиплеере не заявлена.

Проверки выпуска: 109 тестов, сборка macOS и статическая проверка итогового XS. Публикация выполняется только после их успешного завершения. Это **не заменяет проверку настоящего матча** и калибровку таймингов.

# AoE2 Mac Trainer 0.6.1 (7), локальная сборка для Apple Silicon

Исправлено падение 0.6.0 при открытии приложения из ZIP в Finder. Установленная копия теперь читает каталог билдов и оба XS-шаблона из собственных ресурсов.

Исправление вошло в [публичный выпуск 0.7.0](https://github.com/Neftedollar/aoe2-macos-trainer/releases/tag/v0.7.0). Значок 🏰 появляется в верхней строке меню. Повторное открытие приложения в Finder показывает панель. **Control + Option + H** переключает её видимость.

Панель macOS работает в режиме PREVIEW. Для внутриигровой тренировки создай локальный XS-мод через меню 🏰 и выбери его карту в одиночной игре.

# AoE2 Mac Trainer 0.7.0 для Apple Silicon

- Открой тренер до или во время записываемой партии. Меню 🏰 и панель автоматически покажут твою цивилизацию и подходящие билды. Следующую запись тренер подхватит сам.
- Между матчами доступен предпросмотр. В меню «Дичь на старте» можно выбрать «Неизвестно» или количество животных. Для встроенных билдов доступны значения от 1 до 6, для пользовательских — до порога из JSON.
- Исправлено падение при открытии из Finder. Каталог билдов и оба XS-шаблона входят в приложение.

Скачай `AoE2MacTrainer-0.7.0-macos-arm64.zip`, распакуй и перенеси `AoE2MacTrainer.app` в «Программы». Требуются Apple Silicon и macOS 13 или новее. **Control + Option + H** показывает и скрывает панель. Подпись сборки локальная (ad hoc).

Автоподключение работает с открытой записью Feral AoE2 DE. Когда свою цивилизацию нельзя подтвердить, панель показывает «Цивилизация неизвестна». Таймер и шаги на внешней панели управляются вручную. Для целей по игровому времени предназначен XS на тренировочной карте.

В Assets также доступны полный XS-каталог, JSON билдов и `SHA256SUMS.txt`. Для обычного запуска достаточно ZIP приложения.

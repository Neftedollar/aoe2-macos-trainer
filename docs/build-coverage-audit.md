# Аудит покрытия билдов

Срез: **10 ноября 2026 года**. Каталог содержит **56** канонических цивилизаций. Библиотека содержит **15** планов и **283** шага до применения цивилизационных условий. В этой итерации уточнён один существующий план Киданей, а не расширен список цивилизаций.

## Что теперь покрыто

| Вид покрытия | До расширения | После расширения |
| --- | ---: | ---: |
| Хотя бы один план | 27 / 56 | 56 / 56 |
| Общий или специальный FC | 25 / 56 | 56 / 56 |
| Общий или специальный FI | 4 / 56 | 56 / 56 |
| Хотя бы один план с конкретной военной направленностью | 21 / 56 | 21 / 56 |

**FC/FI здесь означают учебную последовательность развития и проверяемые цели эпох. Это не 56 оптимизированных профессиональных FC и 56 военных FI.** Общие семейства — `practice-targets`, с редактируемыми ориентирами Феодал 14:00, Замки 18:30, Империал 27:30. Из исходных девяти планов восемь сохранены, а Кидани обновлены до конкретного открытия скауты → степные всадники.

Киданьский `khitans-scouts-pastures` теперь содержит 33 шага и отдельные цели мельницы, Loom, пастбищ, Domestication, четырёх скаутов, Замков, четырёх/восьми степных всадников и доступных кавалерийских улучшений. Это `source-adapted`, не `match-verified`: механики сверены с DE 188329, сроки требуют калибровки. [План и источники](khitans-scouts-lancers.md).

Полные общие планы:

- `practice-fast-castle-all-civs`
- `practice-fast-imperial-all-civs`

У них явные списки всех 56 цивилизаций и региональные ветки шагов. Нет неявного значения «любая». По текущим извлечённым данным для всех 56 доступны рынок84, кузница103, университет209, осадная мастерская49, ТЦ109 и технологии эпох101/102/103. Проверка завершённой эпохи не подменяется наличием её ресурсов или временем на часах.

## Региональные и начальные ветки

| Группа | Принцип адаптации |
| --- | --- |
| Обычные пункты сдачи | Обычная мельница и лесопилка; военные линии не предполагаются универсальными. |
| Китайцы / майя | Отдельный старт и ранний Loom; не общая кривая производства из трёх крестьян. |
| Гунны | Нет действий строительства домов. |
| Армяне / грузины | Повозка1808 + мельница68; для FI используется общая пара университет209 + мастерская49, а не отсутствующий монастырь104. |
| Инки / муиски / мапуче / тупи | Поселение2556 вместо мельницы68, лесопилки562 и горного лагеря584. |
| Поляки | Фольварк1734 вместо мельницы. |
| Кидани | Пастбища вместо ферм; нет обещаний рыцарей или Bloodlines. |
| Гурджары | Отдельная инструкция о скоте в мельнице; нет автоматического уничтожения всего стада. |
| Бритты / татары | У бриттов пастухи быстрее; у татар в скоте больше еды. Эти бонусы не смешиваются и не заменяются правилом «всегда отказаться от овец». |
| Кхмеры | Обычные здания не называются обязательными условиями переходов. |
| Куманы | Общий план одно-ТЦ; двух-ТЦ бум не подменяется им. |
| Итальянцы / муиски / византийцы | Отдельные подсказки скидок. Муискам скидка только на золото; византийцам — на Империал. |
| Персы / малайцы / бенгальцы / Вэй | Нет универсального вывода о простое ТЦ из времени появления крестьян: отличаются скорость ТЦ/эпох или бонусные появления. |

Подробный счётчик предварительных зданий Feudal для поселений и повозок **ещё нуждается в проверке в самой игре**. Нельзя выводить его только из доступности объекта в дереве технологий. Инструкция не требует произвольно два поселения или лишние бараки; кнопку перехода проверяет игрок, а завершение эпохи — XS.

Наличие здания в `unitGoals` может включать фундамент. Минимумы работников в `allocation` — приблизительные роли, не проверка конкретной ягоды, животного или физической близости к пункту сдачи.

## Варианты пищи

Для каждого семейства есть по два компактных примера: `pushable-hunt` и `small-game`. Каждый требует наблюдения не менее трёх объектов своей категории.

Они подготовлены для **португальцев, турок, испанцев, византийцев, мадьяр и берберов** — обычные стартовые пункты сдачи без необходимости дублировать весь региональный каркас. Это демонстрация условий среды, а не автоматическая поддержка специализированного охотничьего открытия для всех цивилизаций.

- Наблюдение в окрестности исходного ТЦ не доказывает безопасность пути, сохранившийся запас пищи или выполненный подгон. Это история наблюдений, не учёт оставшихся животных.
- Мелкая дичь не исключает существование подгоняемой охоты.
- Отсутствие положительного наблюдения не считается доказанным отсутствием животных.
- Приоритет охоте не запрещает овец, если иначе простаивает ТЦ.
- Нет утверждения, что получены реальные скорости добычи на Mac, экспериментально сравнивались цыплята/кролики или выполнен реальный матч.

Пищевые варианты меняют инструкцию работы с животными; сроки пока общие и не означают экспериментально измеренный выигрыш охотничьего варианта. Типы диких куриц отделены от управляемых домашних, золотые лисы исключены из пищи. Подробности: [food-detection.md](food-detection.md).
